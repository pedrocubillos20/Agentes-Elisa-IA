Preguntas Frecuentes

¿Tienes dudas?

¿Qué incluyen los 20 días gratis?+

Todo. Acceso completo a todas las funciones del plan que elijas. No necesitas tarjeta de crédito. Solo tu API Key de OpenAI para que la IA funcione.

¿Es WhatsApp Web o API oficial? ¿Me pueden banear?+

Elisa IA usa una conexión tipo WhatsApp Web (no API oficial de Meta). Para evitar cualquier problema: no hagas spam masivo, no envíes mensajes a desconocidos sin su consentimiento, y usa un número exclusivo para el negocio. Siguiendo estas recomendaciones, el riesgo es mínimo. Miles de negocios lo usan diariamente sin problemas. Tip: Recomendamos usar un número dedicado para tu negocio, no tu número personal.

¿Qué es una API Key de OpenAI y cuánto cuesta?+

Es una clave que conecta con la inteligencia artificial de ChatGPT. La obtienes en platform.openai.com y solo pagas por uso. Con GPT-4o-mini, 100 mensajes cuestan ~$0.01 USD. Extremadamente económico.

¿Cuál es la diferencia entre Starter y Business?+

Starter ($30): Perfecto si trabajas solo. Tienes hasta 3 líneas de WhatsApp con IA, dashboard y multimedia. Business ($50): Agrega CRM con base de datos de clientes, agenda de citas, equipo multi-usuario con roles (vendedores, soporte, gerentes), asignación de chats y líneas ilimitadas. Ideal si tienes equipo o necesitas gestionar clientes.

¿Puedo intervenir manualmente cuando quiera?+

¡Sí! Envía ".." en cualquier conversación para pausar la IA y tomar el control. Cuando termines, envía "." para reactivarla. También ves todas las conversaciones en tiempo real.

¿Es obligatorio usar ElevenLabs?+

No, es totalmente opcional. Elisa funciona perfecto solo con texto. ElevenLabs permite enviar audios con voz realista si lo deseas.

¿Necesito un número nuevo de WhatsApp?+

No obligatoriamente, pero lo recomendamos. Puedes usar tu número actual escaneando el QR. Sin embargo, para mayor seguridad, es ideal tener un número dedicado al negocio.

¿Cuántos mensajes puedo enviar al mes?+

Ilimitados. No hay límite de mensajes. Solo pagas el consumo de tu API Key de OpenAI, que con GPT-4o-mini es extremadamente económico (~$1 USD por 10,000 mensajes).

¿Puedo cancelar en cualquier momento?+

Sí, sin compromisos ni penalidades. Durante los 20 días gratis no se cobra nada. Si decides continuar, el pago es mensual y puedes cancelar cuando quieras.
