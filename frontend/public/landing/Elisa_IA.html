Preguntas Frecuentes

¿Tienes dudas?

Aquí respondemos las preguntas más comunes

¿Cómo funciona la prueba gratis? +

Te registras con tu email, conectas tu WhatsApp escaneando un QR, y tienes 7 días para probar todas las funciones. No pedimos tarjeta de crédito. Si te gusta, eliges un plan. Si no, no pasa nada.

¿Por qué necesito una API Key de OpenAI? +

Usamos la inteligencia artificial de OpenAI (ChatGPT) para que tu asistente responda. Al usar tu propia API Key, tú controlas exactamente cuánto gastas. Es muy económico: aproximadamente $3-10 USD al mes para la mayoría de negocios.

¿Cómo obtengo la API Key de OpenAI? +

Es muy fácil: Vas a platform.openai.com, creas una cuenta gratis, agregas créditos (mínimo $5 USD), generas tu API Key y la pegas en Elisa IA. Te guiamos paso a paso en la configuración.

¿Puedo tomar el control si quiero responder yo? +

¡Claro! Solo escribe ".." en el chat y la IA se pausa. Respondes tú lo que necesites, y cuando termines escribes "." para que la IA vuelva a atender. Super fácil.

¿Funciona con WhatsApp Business? +

Sí, funciona tanto con WhatsApp normal como con WhatsApp Business. Solo necesitas poder escanear un código QR desde tu teléfono.

¿Puedo cancelar en cualquier momento? +

Sí, sin compromisos ni penalidades. Puedes cancelar cuando quieras desde tu panel de suscripción.
